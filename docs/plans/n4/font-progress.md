# Plain zeros: progress (branch wt/n4-font)

## What was made
- **Generator** `assets/src/2d/fonts-plain-zero.py` (group `2d`, so `tools/build-assets.sh` runs it). It reads
  `assets/fonts/AtkinsonHyperlegible-Regular.ttf` and `-Bold.ttf` and writes `assets/fonts/TideLegible-Regular.ttf`
  and `assets/fonts/TideLegible-Bold.ttf`. Running it twice gives the same bytes (no timestamp is written).
- **The new counter is made of curves, not a polygon.** Atkinson's slashed counter still has two whole quarter
  arcs (right side to top, left side to bottom); the other two quarters are those mirrored about the counter's
  vertical axis, so the counter is four quadratic arcs taken from the font itself. The outline is kept as it is.
  Regular counter x 151..497, y 62..606; Bold x 201..461, y 101..567. The old glyph's hinting instructions are
  dropped for `zero` only (they named points that are gone); the stale `DSIG` table is dropped.
- **`zero.tf`** (what `tnum` switches to) is a composite of `zero` in both weights (offset -4 and -15), so it follows
  the new zero with no change of its own. The script checks this, and checks that no other glyph is built from
  `zero`: none is. `percent` and `fraction` have their own outlines and were never slashed; left as they are.
- **Nothing else changes:** a byte comparison of every other glyph and every advance in `hmtx` finds no
  difference; `zero` keeps advance 648 (Regular) / 652 (Bold), `zero.tf` 639 / 632.

## Where the game loads it
- `game/scripts/UiKit.cs`: only the two lines that name the files (`UiFont`, `UiBold`) now load
  `res://assets/fonts/TideLegible-*.ttf`. Every interface font in the game goes through these two (shop, purse,
  tips, settings pages, modal cards, map labels such as "+403" and the river and building labels). The book's print
  uses Alegreya and Uncial Antiqua (`UiKit.Serif`, `UiKit.Display`), whose zeros are plain; unchanged.
- **The Atkinson originals no longer ship:** `tools/sync-assets.sh` removes `AtkinsonHyperlegible-*.ttf` (and their
  `.import`) from `game/assets/fonts/`, so Godot never imports them and the export cannot pack them
  (`tools/pck-check.py` lists from `game/assets/`, so it agrees). Nothing in the game loaded them besides UiKit.
- Also switched: `tools/asset-audit/index.py` (Tide Legible first, Atkinson as fallback), `docs/asset-gallery/build.py`
  (the gallery lists Tide Legible; the generated `index.html` was not rebuilt), and a note in
  `assets/src/2d/_fetch_fonts.sh` (rerun the generator after a refetch).
