# Tide & Toll

A town-builder where you never draw a road. Villagers wear their own paths into the grass, boats compete with them for the river, and every era inherits the streets of the one before.

## What is in this repository

| Folder | What it holds |
| --- | --- |
| `prototypes/desire-lines/` | Prototype 1: a browser toy that tests whether steering worn paths is fun |
| `assets/` | Art and sound, each one listed in `assets/LEDGER.csv` with its source and licence |

The Godot game (`sim/`, `sim.tests/`, `game/`) is added once Prototype 1 passes its gate.

## Status

Prototype 1 is being built on the `claude/prototype-1` branch.
